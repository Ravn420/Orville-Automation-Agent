## Review procedure

The owner records the review date, checks each evidence path, reassesses likelihood and impact, and updates mitigation or residual risk when controls change. A High residual risk requires an explicit release decision or a tracked remediation task; it must not be silently accepted. New incidents, provider changes, connector changes, dependency changes, or material GUI changes trigger an out-of-cycle review.

This register contains role names and repository-relative evidence paths only. It does not contain credentials, tokens, private URLs, personal data, or claims that deployment-owned controls have been independently verified.
