# Manus Capability Audit Sources

## Official introduction

The official Manus documentation describes Manus as an autonomous general agent that plans, executes, and delivers work products using a virtual computer, internet access, persistent file storage, software installation, custom tools, and context across long tasks.

Source: https://manus.im/docs/introduction/welcome

## Official projects documentation

The official Projects documentation describes persistent reusable workflows with master instructions and a knowledge base of files and documents. It also documents project creation, task inheritance, pinning, drag-and-drop organization, task filtering, privacy boundaries, collaboration, and configuration propagation rules.

Source: https://manus.im/docs/features/projects

## Implications for Orville

The closest standalone-Windows equivalents are a local agent runtime, repository/project workspaces, durable memory and knowledge files, task history and filters, safe tool permissions, explicit approvals, provider-neutral model routing, local scheduling, and exportable artifacts. Managed cloud computers, proprietary hosted models, built-in first-party connectors, and cloud-scale multi-user infrastructure cannot be reproduced literally without corresponding external services; Orville should expose adapters and clear blocked/unconfigured states for those capabilities.
